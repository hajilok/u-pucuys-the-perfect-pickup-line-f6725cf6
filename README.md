# The Perfect Pickup Line

Entry for the [make.fun](https://make.fun/r/41fw6r6c) competition **The Perfect Pickup Line** (`u-pucuys-the-perfect-pickup-line-f6725cf6`).

## Usage

Runs natively on Node 22.18+ (`program/v1` harness) and deterministically writes a single UTF-8 pickup line (1–200 characters, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` for local verification):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
